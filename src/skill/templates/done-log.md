# 🏁 Done

> A record of finished commitments (completed next actions, received waiting-for items, finished projects, cancelled project steps), each with its outcome: what was done, what problems came up and how they were solved.
> **Not a list you act from.** Engage never reads it, the dashboard never counts it as open, and organize never checks it for stalled or orphaned items. It feeds the Weekly Review's "Done since last review" and each project's after-action review.
> One `## YYYY-MM-DD` heading per completion date, newest last. Format:
> ```
> ## YYYY-MM-DD
> - [x] Concrete action text · From: next-actions · Result: done · Project: [[projects#Name|Name]] ^na-short-id-YYYYMMDD
>   - Done: what was actually done
>   - Problems and fixes: what got in the way and how it was solved (or "none noted")
> - [x] Project: Name — desired outcome · From: projects · Result: done
>   - Done: the outcome as achieved
>   - Problems and fixes: the main obstacles across the project, or "none noted"
>   - After action review: intended outcome · what happened · problems and how they were overcome · same or different next time · reusable how-tos (one sub-bullet each)
> ```
> A cancelled *standalone* action, or a dropped someday item, is simply deleted; only project-linked work is worth a record. `Result: cancelled` lines give the reason under `Done:`.
> Kept indefinitely by default; trimming is off unless enabled in `memory/gtd/personalized.md`.
